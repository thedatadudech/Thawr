# ADR 0001: Implementation language is Go

Status: Accepted
Date: 2026-09-02

## Context

Thawr must ship as a single static binary for Linux, macOS and Windows,
talk to WireGuard, embed a web UI, serve gRPC and HTTP, and be readable
by people auditing it for their organisation. The reference WireGuard
userspace implementation (`wireguard-go`), the configuration library
(`wgctrl`), and Tailscale's NAT traversal code are all Go and
permissively licensed.

## Decision

Go, latest stable release, with `CGO_ENABLED=0` for every build. Only
pure-Go dependencies are allowed. Platform-specific code is isolated in
`_linux.go`, `_darwin.go`, `_windows.go` files behind shared interfaces.

## Consequences

- Cross-compilation for all three platforms from one CI job; no
  toolchains, no linked C libraries, no distribution-specific packages.
- The WireGuard ecosystem's Go libraries are used directly instead of
  wrapped.
- Rust and C are excluded even where they would be faster; the data plane
  is WireGuard's, not ours, so Go's performance is sufficient for the
  control plane and the relay.
- Some libraries are excluded (anything requiring CGO, e.g.
  `mattn/go-sqlite3`), which drives ADR 0002.
